## `asy_ats_scan` — ATS scan · 0.05 USDT

Scan an existing résumé the way an applicant-tracking system would: re-parse it, flag format-law violations that scramble in ATS software, and (with a job description) report honest must/nice keyword coverage. Price: 0.05 USDT (x402 on X Layer, eip155:196). Example: &#123;resumeText:"…", jd:"Senior Backend Engineer…"&#125; → format findings + parse-back + coverage. Proof promise: findings come from Assay's deterministic parser and the published Standard's format law — not a guess. Also runnable as a background job via asy_create_dossier_job.
