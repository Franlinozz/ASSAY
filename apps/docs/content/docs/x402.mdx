Paid tools are metered per call with **x402 v2** on X Layer (`eip155:196`), settled in USD₮0 via
the OKX facilitator. Assay needs no account or API key; the buyer still needs a compatible wallet
to authorize a paid replay.

## The flow

1. **Negotiate for free** — `GET /mcp`, `initialize`, and `tools/list` complete without a payment
   challenge. This lets the client establish MCP and choose a service before any billing begins.
2. **POST /mcp · tools/call** — invoke a paid tool with plain JSON-RPC.
3. **HTTP 402** — the `PAYMENT-REQUIRED` header carries a base64 JSON challenge: `x402Version: 2`,
   an `accepts` entry using scheme `exact`, network `eip155:196`, the USD₮0 asset
   `0x779ded0c9e1022225f8e0630b35a9b54be713736`, atomic amount, and pay-to address.
4. **Sign** — the client signs an EIP-3009 exact-scheme authorization for the amount and retries
   the _same_ request with the `PAYMENT-SIG` header (also accepted: `X-PAYMENT`,
   `PAYMENT-SIGNATURE`).
5. **200 + PAYMENT-RESPONSE** — the facilitator verifies and settles on-chain; the response
   carries the settlement proof and your result.

## Marketplace resources

The generic `/mcp` endpoint must keep negotiation free. OKX.AI service cards therefore point to
concrete resources such as `/x402/asy_story_bank` and `/x402/asy_interview_prep`. An unpaid GET or
POST to one of those paid resources returns its own 402 immediately; the paid replay returns the
service result directly. Promotion and freelancer cards use
`/x402/asy_promotion_dossier` and `/x402/asy_freelancer_proof_pack`, which server-bind the correct
`asy_create_dossier_job` variant. Free job status, job result, and seal verification resources
return 200 without x402.

The complete live route map is published under `marketplaceResources` at
[`/.well-known/assay.json`](https://api.assayed.xyz/.well-known/assay.json).

## Guarantees

- **PolicyGate before payment.** A request Assay refuses on policy is refused politely — and never
  charged.
- **Body-bound idempotent recovery.** A settled call is cached against its `Idempotency-Key` (or
  the payment signature hash). A retry with the same key and canonical arguments recovers the
  original result even if the payment header was lost. Reusing the key for different input returns
  `409 idempotency_conflict` — never another charge and never another person’s result.
- **Free means free.** `asy_verify`, `asy_job_status`, and `asy_job_result` are never gated.
- **No charge before tool invocation.** `GET`, malformed transport requests, `initialize`,
  `tools/list`, and notifications never enter payment handling. Only `tools/call` for a paid tool
  can return a 402.
- **Fixed prices.** The table in [pricing](https://assayed.xyz/pricing) is the table the paywall
  enforces, published machine-readably at
  [`/.well-known/assay.json`](https://api.assayed.xyz/.well-known/assay.json).
